Pré-processamento e Engenharia de Features

⚙️
Pipeline sklearn encapsulado Todo o pré-processamento foi encapsulado em um Pipeline, garantindo as mesmas transformações no treino e teste sem vazamento de dados.
  • Remoção de colunas sem variabilidade — STDs:AIDS e STDs:cervical condylomatosis (858 valores = 0).
  • Missing Indicators — criada coluna _preenchido (1 = respondeu) para cada feature com NaN; nulos substituídos pela média.
  • Agrupamento de indicadores idênticos — todas as 11 variáveis de DST com 87,76% de resposta consolidadas em _respondido.
  • Redução de redundância — Tabagismo — Smokes (years) × Smokes (packs/year) → smoke_year_packs.
  • Transformação log1p — aplicada em Age, parceiros, primeira relação, gestações. Reduz outliers e normaliza assimetria.
  • Feature engineering — Contraceptivos — contraceptive_mid_risk (uso 3–15 anos) e contraceptive_exposure.
  • Remoção temporal de STDs — STDs: Time since first diagnosis removida por redundância com a coluna "last".
  • Atributos estratégicos combinados — sexual_risk, smoke_age_risk, has_std, std_age_risk, combined_risk.

Discussão e Conclusões

Mesmo com SMOTE, ajuste de threshold, GridSearchCV e feature engineering, o melhor AUROC foi 0,737 e o melhor Recall foi 36%. Os resultados são academicamente válidos, mas insuficientes para produção clínica.

🚧
Limitações
  • Dataset pequeno (858 registros, 55 positivos) limita o aprendizado;
  • SMOTE gera amostras sintéticas — não é bem visto para validação clínica;
  • Recall de 36% é inadequado para triagem real (falsos negativos = risco de vida);
  • Correlações fracas entre features e target — baixo poder preditivo intrínseco.
💡
O que melhoraria os resultados
  • Mais dados reais — coletar >500 casos positivos confirmados;
  • XGBoost / LightGBM — boosting supera RF em datasets pequenos e desbalanceados;
  • Curva Precisão-Recall — mais informativa que AUROC para classes muito raras;
  • K-Fold estratificado (k=10) — estimativas mais confiáveis com poucos dados.
