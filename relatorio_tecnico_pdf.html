1.Sobre o Dataset

O dataset "Risk Factors for Cervical Cancer" foi coletado no Hospital Universitário de Caracas, Venezuela, e disponibilizado no UCI Machine Learning Repository. Ele contém informações demográficas, hábitos pessoais, histórico médico e resultados de quatro exames clínicos de 858 pacientes.

Objetivo do Projeto Construir um modelo de aprendizado de máquina capaz de realizar a triagem de pacientes, identificando quais têm maior probabilidade de apresentar resultado positivo na biópsia — o exame padrão-ouro para diagnóstico de câncer do colo do útero.

3.Estratégias de Pré-processamento

3.1 — Leitura com tratamento de missing

O dataset foi relido usando na_values='?', convertendo automaticamente todos os pontos de interrogação em NaN, habilitando operações estatísticas nativas do Pandas.

dataset = pd.read_csv("risk_factors_cervical_cancer.csv", na_values='?')

3.2 — Indicadores de Missing (Missing Indicators)

Para cada coluna com dados faltantes, foi criada uma coluna binária indicadora:

  • 1 = paciente respondeu a questão
  • 0 = paciente se recusou a responder

Os valores faltantes foram imputados com a média da coluna. Essa combinação preserva a informação de comportamento de não-resposta, que pode ser estatisticamente relevante (ex.: pacientes que não revelam histórico de DSTs).

for col in colunas:
    if dataset[col].isnull().any():
        dataset[f"{col}_preenchido"] = dataset[col].notnull().astype(int)
        dataset.fillna({col: dataset[col].mean()}, inplace=True)

3.3 — Consolidação de colunas redundantes

Verificou-se que múltiplas colunas _preenchido de DSTs tinham distribuição idêntica (87,76% respondidas). Essas colunas foram consolidadas em um único indicador representativo por grupo, reduzindo a dimensionalidade.

3.4 — Feature Engineering — Tabagismo

Criação da feature smoke_year_packs = anos de fumo × maços por ano. Representa a exposição acumulada ao tabaco de forma mais informativa do que variáveis separadas. Antes da multiplicação, garantiu-se consistência: se Smokes = 0, os demais campos foram zerados.

dataset.loc[dataset['Smokes'] == 0, ['Smokes (years)', 'Smokes (packs/year)']] = 0
dataset['smoke_year_packs'] = dataset['Smokes (years)'] * dataset['Smokes (packs/year)']
dataset.drop(columns=['Smokes (years)', 'Smokes (packs/year)'], inplace=True)

3.5 — Remoção de variáveis sem variabilidade

As colunas STDs:AIDS e STDs:cervical condylomatosis foram removidas por apresentarem valor 0 em todos os 858 registros. Colunas constantes não carregam informação preditiva e podem introduzir ruído nos cálculos de correlação.

Justificativa das Escolhas A imputação por média é simples e funciona bem quando associada ao indicador binário. Remover linhas com missing reduziria o dataset de 858 para ~650 amostras (já pequeno), piorando o treinamento. O indicador de missing captura o padrão de recusa — potencialmente informativo para o modelo.
4.Modelos Utilizados e Por Quê

4.1 — Random Forest (Baseline)

Random Forest é um ensemble de Árvores de Decisão treinadas sobre subconjuntos aleatórios de amostras e features. A predição final é a votação majoritária entre todas as árvores.

Justificativa da escolha:

  • Robusto a outliers (ex.: 28 parceiros sexuais, 84 anos de idade);
  • Funciona bem com dados mistos (variáveis binárias + contínuas + categóricas);
  • Suporta o parâmetro class_weight para lidar com desbalanceamento sem oversampling;
  • Alta interpretabilidade via importância de features;
  • Excelente desempenho em datasets tabulares de tamanho moderado.

4.2 — Transfer Learning com Modelos Auxiliares

A abordagem usa os quatro exames como tarefas relacionadas. Três modelos Random Forest foram treinados nos exames auxiliares (Hinselmann, Schiller, Citologia), e as suas probabilidades preditas foram adicionadas como novas features para o modelo principal (Biópsia).

Intuição clínica: os quatro exames avaliam o mesmo tecido cervical. Uma paciente com alta probabilidade de Schiller positivo provavelmente tem maior risco de biópsia positiva também — os exames compartilham fatores de risco.

Interpretação dos Resultados

Alta Acurácia ≠ Bom Modelo para Triagem Médica Um modelo que prevê SEMPRE "negativo" já acertaria 93,6% (pois apenas 6,4% são positivos). O Recall de 9% na classe positiva é o problema crítico: o modelo detecta apenas 1 de cada 11 casos reais de biópsia positiva. Em triagem médica, falsos negativos são muito mais custosos que falsos positivos.
Por que o Transfer Learning não melhorou?
  • O dataset é muito pequeno (11 positivos no teste = estatística instável);
  • Os modelos auxiliares usam as mesmas features — informação redundante;
  • O RF Baseline já captura as correlações internas entre as variáveis;
  • Com apenas 11 casos positivos no teste, 1 caso a mais ou menos altera drasticamente recall e precisão.

7.Conclusões e Trabalhos Futuros

Conclusões

  • O dataset é desafiador: pequeno, muito desbalanceado (6,4% positivos) e com dados faltantes por privacidade.
  • O pré-processamento com indicadores de missing foi uma estratégia adequada para preservar informação de recusa.
  • O Random Forest com class_weight é uma escolha robusta para dados tabulares desbalanceados.
  • O Transfer Learning não trouxe ganho adicional, possivelmente pela redundância de features e pelo tamanho limitado do dataset.
  • A acurácia de 94% é enganosa: o Recall de 9% na classe positiva é inaceitável para triagem clínica.

Sugestões para Melhorias

  • SMOTE / Oversampling: gerar amostras sintéticas da classe minoritária;
  • Ajuste de threshold: em vez de 0.5, usar 0.2–0.3 para aumentar o Recall;
  • Otimização de hiperparâmetros: GridSearchCV ou Optuna;
  • Métricas adequadas: AUC-ROC, AUC-PR (Área sob a Curva Precisão-Recall);
  • Mais dados: 858 amostras com 55 positivos é insuficiente para generalização robusta;
  • XGBoost / LightGBM: comparar com outros algoritmos de ensemble.
Impacto Potencial Um modelo com Recall elevado (>80%) na classe positiva poderia ser usado como ferramenta de triagem de baixo custo em postos de saúde, priorizando quais pacientes devem ser encaminhadas para biópsia, reduzindo custos e aumentando a cobertura do rastreio.
